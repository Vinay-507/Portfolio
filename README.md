# Vinay Bokka Futuristic Portfolio

Premium React + Vite portfolio for Vinay Bokka, built with Tailwind CSS, Framer Motion, GSAP, React Three Fiber, Three.js, Lenis smooth scroll, lucide-react icons, and shadcn-style UI primitives.

## Features

- Cinematic fullscreen 3D hero with particles, glowing core, floating cyber objects, and mouse-reactive lighting.
- Resume-backed sections for about, skills, projects, certifications, journey, and contact.
- Lenis smooth scrolling, GSAP scroll reveals, Framer Motion transitions, scroll progress, page loader, custom cursor, sound toggle, and glassmorphism UI.
- Responsive layouts for mobile, tablet, laptop, and ultrawide screens.
- Optimized Vite chunk splitting for Three.js and animation libraries.

## Install

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push the project to GitHub.
2. Import the repository in Vercel.
3. Use the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

## Deploy to Netlify

1. Push the project to GitHub.
2. Create a new Netlify site from the repository.
3. Use:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. Deploy.

## Content Source

Content is personalized from `Vinay Resume.pdf`, including education, projects, internships, certifications, skills, leadership activities, and contact details. The education copy uses the corrected wording that Vinay completed B.Tech in Computer Science Engineering for 2022-2026.
